# MokuIsland

Статический сайт [Moku](https://drugalochek.github.io/MokuIsland/) в стиле приложения: чёрное стекло, мягкие скругления и спокойный лавандовый акцент. Сборка для публикации не требуется. GitHub Pages использует `main`, корень репозитория.

## Интерактивность

- Островок в первом экране сворачивается и раскрывается. Вкладки доступны мышью и стрелками клавиатуры.
- Демо-настройки меняют скругление и цвет. Папка раскрывается; пример записи буфера копируется только по нажатию. Доступа на чтение буфера нет.
- Музыкальная волна — явно обозначенная демо-анимация без звука.
- Глазки смотрят на курсор, интересуются при наведении и радуются нажатию. Через 22 секунды бездействия отдыхают. Самостоятельных перелётов и случайных эмоций нет.
- Помощник открывается только по нажатию. Его можно скрыть на текущий сеанс и вернуть из футера. Системная настройка уменьшения движения соблюдается; в скрытой вкладке анимация останавливается.
- Скриншоты открываются в модальном окне. `←`/`→` листают, `Esc` закрывает, фокус возвращается к исходной кнопке.

## Релизы

`js/release.js` выбирает реальный стабильный x64-установщик из GitHub Releases репозитория `drugalochek/Moku`. Версия извлекается из имени файла, а не из названия релиза. При недоступности API остаётся рабочая ссылка на установщик 2.12.4; неопубликованная сборка автоматически не подставляется.

## Файлы

- `index.html` — семантическая разметка и работающие без JavaScript ссылки скачивания.
- `styles.css` — оформление и адаптивность.
- `js/app.js` — интерактивность, доступность и связь компонентов.
- `js/eye-state.js` — независимая машина состояний глаз и пружинное слежение.
- `assets/` — оптимизированный логотип и WebP-копии существующих [скриншотов Moku](https://github.com/drugalochek/Moku/tree/main/Screenshots). Оригинальные изображения в исходном репозитории не изменяются.

## Проверки

Node.js 24:

```sh
npm ci
npm test
npx playwright install --with-deps chromium
npm run test:browser
```

Для уже установленного Chromium можно указать `CHROMIUM_PATH=/path/to/chromium`. Браузерные проверки запускают локальный статический сервер, проверяют интерактивность, клавиатуру, адаптивность от 320 до 1920 px, уменьшение движения, резервное скачивание и доступность axe. Отчёт и контрольные скриншоты сохраняются в `test-results/` (не публикуются вместе с исходниками).

Production-сайт не использует сторонние JavaScript-библиотеки, внешние шрифты, аналитику или токены GitHub. NPM-пакеты нужны только для проверок.
