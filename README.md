# Moku Island

Публичный сайт Moku: https://drugalochek.github.io/MokuIsland/

## На сайте

- Чёрное стекло, мягкие скругления и лавандовый акцент в стиле приложения.
- Реальные скриншоты с увеличением, подробные возможности, ответы и скачивание. HTML-симуляции приложения нет.
- Свободно летающий помощник: следит глазами за курсором, останавливается при наведении или фокусе, даёт редкие подсказки по разделам. Внизу предлагает кнопку «Наверх со мной» и сопровождает прокрутку.
- Настройка ОС «уменьшить движение» отключает свободный полёт, моргание и анимированный подъём. Помощника можно скрыть до конца сеанса и вернуть из подвала.

## Автоматическая информация о выпуске

Источник: стабильный опубликованный релиз `drugalochek/Moku` (`/releases/latest`).

- Версия и ссылка берутся из существующего `Moku-Setup-<версия>-x64.exe`, не из потенциально устаревшей ссылки в описании.
- Название релиза приводится к версии выбранного установщика. Исходное название сохраняется в `release.json` как `githubName` для диагностики.
- Размер и дата — свойства установщика; описание и список «Возможности» — текст релиза. Markdown превращается в безопасный текст, а не исполняемый HTML.
- Черновики, предварительные выпуски и ссылки вне официального репозитория не используются.
- Браузер читает опубликованный `release.json`, затем проверяет API при открытии и раз в пять минут, пока вкладка видна. При недоступности API сохраняются проверенные ссылки.
- GitHub Actions каждый час (23-я минута), при изменении `main` и по `workflow_dispatch` заново собирает сайт с актуальными данными. Расписание GitHub может задерживаться; обновление не обязательно мгновенное.
- Авторизованный запрос при сборке использует только стандартный временный `GITHUB_TOKEN`. В клиентский код и опубликованные файлы никакие токены не попадают. Публикация выполняется workflow из `main`; существующий источник Pages `main /` тоже поддерживается.
- `release.json` в репозитории — проверенный резерв на случай недоступности источника. Сайт не устанавливает обновления в само Windows-приложение.

## Разработка и проверки

Node.js 24, без сборщика и CDN-зависимостей в браузере.

```sh
npm ci
npm test
npx playwright install --with-deps chromium
npm run test:browser
node scripts/build-site.mjs
python3 -m http.server 4173 --directory dist
```

`CHROMIUM_PATH=/usr/bin/chromium npm run test:browser` использует системный Chromium. Отчёты и снимки автоматических проверок — `test-results/` (не публикуются).

Сборка публикует только HTML/CSS/JS, изображения и публичный JSON релиза. Тесты, зависимости, исходные архивы и рабочие файлы не входят в артефакт Pages. Исходные пользовательские изображения и архив в репозитории сохранены.
